# M1.1 电感：电流的惯性 & 伏秒平衡

## 核心直觉
- 电感 = 装满水的长水管。**电压决定的不是电流有多大，而是电流变化有多快**（类比牛顿第二定律：力决定加速度）。
- 电压为 0 时，电流**保持不变**（不是变成 0）。
- 电流不能突变。硬切断电流的瞬间，电感会产生极高电压（100µH、20A、100ns 内切断 → 约 20000V），所以每个开关都必须有**续流路径**（体二极管）。
  - ⚠️ 二极管**不消耗**电流，它只给电流提供继续流动的路，同时把电压钳位在母线附近。

## 最少公式
- $v_L = L\,\dfrac{di}{dt}$
  - $v_L$：电感两端电压
  - $L$：电感量，即“惯性”有多大
  - $di/dt$：电流变化的速度
- 电压分段恒定时：$\Delta I = \dfrac{V\cdot\Delta t}{L}$，即伏秒 ÷ 电感 = 电流变化量
- 写成代码：`i += (v / L) * dt;`（这就是积分，M5 和 M6 会再用到）
- **伏秒平衡（稳态）**：一个周期内，正的伏秒 = 负的伏秒；换个说法，**电感电压的平均值为 0**

## 推导 U = D·E（降压斩波 / 逆变桥的一个桥臂）
方法：**把开关电路按开关状态拆成两个普通电路**，再用“左端电位 − 右端电位”求出电感电压。

| 状态 | 持续时间 | 电感电压 |
|---|---|---|
| 上管导通 | D·T | E − U（正，电流涨） |
| 上管关断，二极管续流 | (1−D)·T | 0 − U = −U（负，电流跌） |

带符号相加为 0：$(E-U)DT + (-U)(1-D)T = 0 \Rightarrow U = DE$

## 工程意义
- 相电流纹波 ∝ 伏秒 / L。电感减半，纹波翻倍；PWM 频率翻倍可以把纹波拉回来，但代价是**开关损耗也翻倍**。低电感的轮毂电机在选 PWM 频率时就面临这个取舍。

## 我答错过的地方（复习重点）
1. 关断段电压答成了 −12V（应为 −U = −36V）：**伏秒相等，不是电压相等**。
2. 推出 U = ED/(2D−1)：把“大小相等”和“带符号相加为 0”两种写法混用，负负得正。
   - ✅ 习惯：**推出公式后，代入数值或极限（D=0、D=1）检查一下**。如果降压电路的输出比输入还高，说明一定错了。
