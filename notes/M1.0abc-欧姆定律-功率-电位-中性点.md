# M1.0 a/b/c 欧姆定律、功率、电位与地、电机中性点

## a. 电流、电压、电阻 → 欧姆定律
- 水路类比：电流 = 流量（A），电压 = 水压差（V），电阻 = 管子有多细（Ω）。**有压差才有流动。**
- $U = I \times R$。三个量知道两个，就能求第三个。
- 工程：**采样电阻（shunt）**。ADC 只能测电压，代码用 $I = U/R$ 反算电流。1mΩ、20A → 20mV。

## c. 功率与发热
- $P = U \times I$（每秒消耗的能量，单位 W）
- 电阻上：把 $U = IR$ 代入，得 $P = I^2 R$。**电流翻倍 → 发热 ×4**
- 工程：
  - 采样电阻选小（0.5–2mΩ）：10mΩ 在 20A 时要发热 4W，1mΩ 只有 0.4W
  - MOSFET 全开时相当于一个小电阻：20² × 3mΩ = 1.2W
  - 爬坡时电流从 15A 变成 30A，MOS 和绕组的发热变成 4 倍

## b. 电位与“地”
- 楼层类比：GND = 一楼地面（0V）；电位 = 某点比地高多少伏；电压 = 两点电位之差。
- $U_{AB} = V_A - V_B$，**下标的顺序就是相减的顺序**；$U_{BA} = -U_{AB}$。
- ebike：电池负极 = GND。桥臂中点 A：上管导通时为 48V，下管导通时为 0V。
- ADC 读到的每一个数，都是相对 MCU GND 的电位。

## 电机中性点 N（星形连接）
- 三相绕组各有一端接相线，另一端拧在一起，这个点就是 N（在电机内部，一般不引出）。
- 每相绕组承受的电压 = 相线电位 − 中性点电位，例如 $U_{AN} = V_A - V_N$。
- 推导（把三相绕组看成相同的电阻 R）：
  - $I_A = (V_A - V_N)/R$，$I_B = (V_B - V_N)/R$，$I_C = (V_C - V_N)/R$
  - 在 N 点用 KCL：$I_A + I_B + I_C = 0$
  - 两边乘以 R：$V_A + V_B + V_C - 3V_N = 0$，得 $V_N = \dfrac{V_A+V_B+V_C}{3}$（三根弹簧拉一个环，环停在平均位置）
- 例：$V_A = 48$、$V_B = V_C = 0$ → $V_N = 16$，$U_{AN} = 32$，$U_{BN} = U_{CN} = -16$。一相绕组只分到母线电压的 **2/3**。
- $U_{AN} + U_{BN} + U_{CN} = R(I_A + I_B + I_C) = 0$，**这是 KCL 的直接结果，不是巧合。**
- 工程：因为 $I_A + I_B + I_C = 0$，FOC 只需要采两相电流，第三相用 $I_C = -I_A - I_B$ 算出来。
