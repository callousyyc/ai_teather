# 上课

参数：`$ARGUMENTS`（可为空）

1. 读 `progress/learner.md`、`progress/review.md`、`curriculum.md`。
2. 确定本次内容：
   - 参数为空 → 从 learner.md 的“当前位置”继续；如果有到期的复习项，先复习。
   - 参数是模块编号或概念名 → 在 `curriculum.md` 里定位。如果它的前置概念还没学，先告诉学生，并建议先补哪一个。
3. 如果这个概念有教材出处，用 Read 打开对应页面的图片核对（PDF 页 = 书页 + 8）。
4. 严格按照 CLAUDE.md 的教学原则讲**一个**概念：直觉 → 最小数学（说明每个符号的物理意义）→ 工程意义（用 ebike/FOC 举例）。适合的话，在 `sims/` 做一个仿真图。
5. 提 1–2 个引导性问题，然后停下来等回答。
6. 一个小节结束时，执行 CLAUDE.md 里“一个小节学完”的流程。
