# 复习

1. 读 `progress/review.md`，挑出到期日 ≤ 今天的条目（今天的日期用 `date +%F` 确认）。没有到期项就说明下一次复习是哪天，并建议继续 `/teach`。
2. 逐题提问，等学生回答，不要提前给答案。
3. 批改：答对 → 间隔升一档（1→3→7→21→60 天）；答错 → 简短讲解（引用教材页），间隔重置为 1 天。
4. 更新 `progress/review.md` 的到期日，在 `progress/log.md` 追加一行复习记录。
