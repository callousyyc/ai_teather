# 测验

参数：`$ARGUMENTS`（范围、题型、题数，可以为空；默认：已学内容、5 题、几种题型混合）

1. 读 `progress/learner.md`，确定已学范围和薄弱点；和薄弱点相关的题目占一半左右。
2. 题型混合，都尽量贴近 ebike 电控的实际场景：
   - 直觉题：为什么、比较、预测“如果……会怎样”
   - 计算题：纹波、平均电压、时间常数、dq 电压/转矩、PI 参数等（答案先用 Python 算好）
   - 波形/代码题：描述某段波形；或者给出一段 FOC/PI 代码片段，让他找错误或解释某一行
   - 书后习题：属于教材范围的内容可以用（Read 习题页的图片，并注明题号）
3. **一次只出一道题**，等他回答后再批改：答对的，说明好在哪里；答错的，先诊断错因，再针对性地讲。
4. 全部结束后，给出得分和每题评语，然后更新 `progress/learner.md`、`progress/review.md`（答错的题加入 1 天后复习）和 `progress/log.md`。
