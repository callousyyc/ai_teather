# AI 老师 · 电机控制底层原理

在这个文件夹里打开 Claude Code，它就会按 `CLAUDE.md` 的规则当你的一对一电机控制教授。课程路线见 `curriculum.md`：电路 → 电力电子 → PMSM → 自动控制 → 仿真 → z 变换 → 代码。

## 怎么用

| 命令 | 作用 |
|---|---|
| `/teach` | 从上次的进度继续上课 |
| `/teach M3.4` / `/teach 死区` | 讲指定模块或概念 |
| `/quiz` / `/quiz M2 计算题 5` | 出题测验、逐题批改 |
| `/review` | 做到期的间隔复习题 |
| 直接提问 | 随时问，老师会翻书回答并标注页码 |

学习进度存放在 `progress/`，每节课的笔记在 `notes/`，波形仿真脚本和图片在 `sims/`。

## 换成第 6 版

第 6 版 PDF 被企业加密系统加密了（文件头是 `%TSD-Header`），脚本读不了。请先用授权的阅读器另存一份**未加密**的 PDF（前提是公司政策允许），然后运行：

```bash
python tools/ingest.py "路径/电力电子技术第6版.pdf" --name pe6
```

脚本会把每页渲染成图片并做 OCR，中断后重新运行会接着做。跑完以后对老师说一句“根据 kb/pe6 重建 syllabus.md”，之后上课就会改用第 6 版。

## 再加一本书

同一条命令，换一个 `--name` 即可（例如电路、电机控制的书），`tools/search.py` 会在所有书里一起检索。
